# DIY 移动机械臂功能总结

## 项目概述

本项目搭建了一套低成本 DIY 移动抓取机器人。系统由三轮全向底盘、六自由度从臂、主臂遥操作器、腕部相机、底部相机以及可选外部相机组成，目标是在真实桌面环境中完成“寻找物体、移动接近、夹取物体、放置到目标容器”等闭环操作。

## 已实现功能

1. **主从臂遥操作**
   - 用户可以通过主臂直接示教从臂动作。
   - 从臂能够跟随主臂完成抬起、伸出、转腕、夹爪开合等动作。
   - 夹爪支持连续开合，能够适应不同大小物体。

2. **基于相机的目标寻找与底盘对准**
   - 系统可以识别橘子、碗等目标物体。
   - 底部相机用于粗定位，腕部相机用于靠近后的精细对准。
   - 底盘可以自动搜索、前进和旋转微调，让目标进入机械臂更容易操作的位置。

3. **橘子抓取**
   - 机器人可以自动寻找橘子并移动到合适距离。
   - 当橘子位于腕部相机合适区域后，机械臂会执行抓取动作。
   - 已经实现从“看到橘子”到“夹起橘子”的完整流程。

4. **橘子放入碗**
   - 机器人夹起橘子后，可以继续寻找碗的位置。
   - 通过视觉对准让碗进入合适视野范围。
   - 机械臂可以将橘子移动到碗上方并释放，实现放入碗中的任务。

5. **单目与双相机感知**
   - 单目腕部相机可以用于近距离操作和精细抓取。
   - 双相机模式可以同时利用腕部视角和外部全局视角，提高环境感知能力。
   - 系统可以根据任务需求选择不同相机组合。

## 功能特点

- **低成本可复现**：主要由舵机、摄像头、移动底盘和 3D 打印结构组成。
- **移动操作一体化**：不仅能移动到目标附近，也能完成机械臂抓取和放置。
- **可学习新任务**：通过人工示教，机器人可以继续学习新的桌面操作任务。
- **适合教学和实验**：系统结构清晰，便于展示机器人感知、控制和学习的完整流程。
